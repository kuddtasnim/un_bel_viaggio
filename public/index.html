About

Un Bel Viaggio

A personal tool for conscious travel. Not a booking platform — a place to plan intentionally, reflect deeply, and remember what actually mattered.

Four core moments

  • Before — AI trip planning around your rhythm and interests
  • During & after — reflection, notes, scans, multilingual publishing
  • Between trips — inspiration, traveller profile, knowledge base
  • Packing — smart lists built on your past experience

Why I travel

Collect moments, not things

A particular quality of light, the smell of a morning market, the way people move in a city — these are what stay.

Slow down deliberately

One neighbourhood per day. One café, really noticed. The rhythm of a place takes time to absorb.

Practice noticing

Travel is an exercise in attention. What do I actually see? What do I walk past without realising?

Return differently

A good trip changes how you read the place you came from. Distance helps you see home more clearly.

Build a personal knowledge base

Every transit solved, every shortcut found, every discovery worth repeating — captured before it fades.

Write while it's still alive

The detail that felt unforgettable becomes vague in 48 hours. Notes written on the spot are the most honest ones.

Tech stack

  • React + Vite + TypeScript + Tailwind CSS
  • Supabase — database (PostgreSQL), Auth, file Storage
  • OpenAI API — reflection summaries, translations (RU/EN/FR)
  • Mapbox — interactive trip map
  • Web Speech API — voice recording & transcription
